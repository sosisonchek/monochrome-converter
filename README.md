# Monochrome converter

Позволяет переводить любую картинку в монохром из цветов, предоставленных в config.ini.
Цвета были взяты из https://catppuccin.com/palette/

#### Требования:
- Numpy
- Pillow (PIL)

#### Добавление в PATH
1. Откройте эмулятор терминала в директории этого проекта.
2. Введите `pip install -e .`.

#### Аргументы:
monochrome [file НАЗВАНИЕ ФОТОГРАФИИ] [--size РАЗМЕР] [--white ЦВЕТ] [--black ЦВЕТ] [--sharpness РЕЗКОСТЬ ПЕРЕХОДА]

Пример использования:
monochrome yuuri.jpg --size 1920x1080

* --size - Размер картинки при выводе
* --white - Цвет для ярких пикселей (цвета см. в config.ini)
* --dark - Цвет для тёмных пикселей (цвета см. в config.ini)
* --sharpness - Резкость перехода между яркими и тёмными пикселями
